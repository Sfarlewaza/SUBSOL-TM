# Discord Server Architecture — Pirate Network Hub

This document outlines the channel structure, role hierarchy, permission rules, and self-claim verification setup for the community Discord server. Designed for zero-bloat maintenance and privacy-first onboarding via the **Human Bridge** mechanism.

---

## 1. Role Hierarchy (Top to Bottom)

> **Important:** In Discord Server Settings $\rightarrow$ Roles, the `Bot` role must sit **above** all member rank roles (`Pirate Broadcaster` down to `Listener`) so automated role assignment works properly.

| Order | Role Name | Color Hex | How It Is Earned | Core Permissions & Perks |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `Organizer` | `#D9381E` (Signal Red) | Core team / Admins | Full server management, access to `#organizari`. |
| 2 | `Bot` | `#5865F2` (Blurple) | Automated verification bot (Carl-bot / YAGPDB) | `Manage Roles`, `Manage Messages`, `Send Messages`. |
| 3 | `Pirate Broadcaster` | `#33FF00` (Phosphor Green) | 10+ locations unlocked + 3 live gigs/contributions | Access to `#secret-gigs` (2-hour advance drops), ability to submit new location riddles. |
| 4 | `Roadie` | `#E67E22` (Amber) | 6+ locations unlocked OR 1 live workshop/talk | Early RSVP (24h window) for small gigs and live DIY screen-printing sessions. |
| 5 | `Tape Trader` | `#EAE6DF` (Samizdat Paper) | 3+ locations + 2 quizzes (`!tune-77B-[handle]`) | Unlocks `#gear-talk-and-sells`, `#jam-sessions`, and 1 single-use web invite key. |
| 6 | `Listener` | `#808080` (Static Grey) | Default role upon joining / initial entry | Read access to `#events` riddles, `#diy-culture`, `#memes-and-networking`, and `#frequency-check`. |

## 2. Channel Structure & Permissions

### Category 1: `// SIGNAL TRANSMISSION` (Onboarding & Drops)
* **`#rules-and-lore`** *(Read-Only)*
  * **Purpose:** Explains the 1977 Samizdat ethos, the Human Bridge verification ritual, and community rules.
  * **Permissions:** `@everyone` (View: ✅, Send: ❌).
* **`#frequency-check`** *(Verification Channel)*
  * **Purpose:** Where users paste their unique self-claimed codes generated by the web app (e.g., `!tune-77B-alex`) to unlock higher ranks.
  * **Permissions:** `Listener`+ (View: ✅, Send: ✅, Read Message History: ❌ — keeps previous codes hidden; bot auto-deletes messages).
* **`#events`** *(Public Drops & Riddles)*
  * **Purpose:** Bi-weekly location riddles, partial GPS coordinates, and announcements for public artist talks and workshops.
  * **Permissions:** `Listener`+ (View: ✅, Send: ❌, Add Reactions: ✅).

### Category 2: `// THE UNDERGROUND` (Active Scene Building)
* **`#jam-sessions`** *(Band Finder & Rehearsals)*
  * **Purpose:** Looking for drummers, bassists, vocalists, or sharing local Timișoara rehearsal room availability.
  * **Permissions:** `Tape Trader`+ (View: ✅, Send: ✅).
* **`#gear-talk-and-sells`** *(Instruments & Amps)*
  * **Purpose:** Peer-to-peer second-hand gear trading, pedal/amp discussions, and local repair tips.
  * **Permissions:** `Tape Trader`+ (View: ✅, Send: ✅).
* **`#diy-culture`** *(Upcycling & Zines)*
  * **Purpose:** Live silkscreen printing schedules, patch/pin designs, bootleg cassette art, and local zine sharing.
  * **Permissions:** `Listener`+ (View: ✅, Send: ✅).
* **`#memes-and-networking`** *(General Hangout)*
  * **Purpose:** Off-topic banter, gig photos, and casual scene networking.
  * **Permissions:** `Listener`+ (View: ✅, Send: ✅).

### Category 3: `// CLANDESTINE` (Gated High-Trust Channels)
* **`#secret-gigs`** *(Hidden Channel)*
  * **Purpose:** Coordinates and passwords for underground shows announced 2 hours prior to doors opening.
  * **Permissions:** `@everyone` (View: ❌), `Pirate Broadcaster` (View: ✅, Send: ❌).
* **`#organizari`** *(Private Core Team)*
  * **Purpose:** Riddle planning, venue coordination, merch logistics, and hackathon/project ops.
  * **Permissions:** `@everyone` (View: ❌), `Organizer` (View: ✅, Send: ✅).

## 3. Self-Claim Role Setup (Carl-bot / YAGPDB)

To avoid OAuth2 surveillance and heavy backend maintenance, users manually carry their rank code from the web app into `#frequency-check`.

### Custom Command Logic
1. **Trigger Type:** Starts with `!tune-77B-` (for `Tape Trader`) / `!roadie-77B-` (for `Roadie`) / `!pirate-77B-` (for `Pirate Broadcaster`).
2. **Channel Restriction:** `#frequency-check` only.
3. **Bot Actions:**
   * Delete user's trigger message immediately (`{delete}`).
   * Assign target role (`{role: Tape Trader}`).
   * Send auto-deleting confirmation (`{delete:5s}`):
     ```text
     // SIGNAL LOCKED FOR {user}. FREQUENCY VERIFIED. ACCESS GRANTED.
     ```
